Session flow

How the files work together.

The three files create a complete pedagogical arc — from activation to application to reflection.

1
Lead-in — student opens alone or with teacher
Conceptual questions activate what the student already knows. No theory yet. The teacher uses the Teacher Companion to guide the discussion.
2
Main module — theory + practice
The student works through the tabs. Theory is introduced through benchmarks and character scenarios. Practice is written and oral, with reveals available.
3
Your Reality tab — application
Conceptual questions connect the module to the student's actual context. No memory triggers. The student answers with what they think and know.
4
Teacher Companion — throughout
The teacher uses the companion during all three phases. Oral questions are marked ◉. Transition phrases are in coral. What to observe is specific per question.
Questions

The Question Rule.
Concept, not memory.

Every question in EIC materials must invite the student to think about a concept, idea, or possibility — not to retrieve a specific memory. Students respond with what they think and know, not what they lived and remember.

Never use
Situational memory questions
These questions require the student to retrieve a specific memory. If the memory is not there, the question fails and the student goes silent.
Examples to avoid
"Have you ever..." / "Do you remember a time..." / "Think of a situation where you..."
Always use
Conceptual opinion questions
These questions invite the student to share what they think, observe, or believe. Any experience can answer them — or no experience at all.
Examples to use
"What makes X happen?" / "When does Y work?" / "What is the difference between A and B?"
✕
"Have you ever had to convince a CFO?" — requires specific memory
✓
"What makes a financially-focused person hard to convince?" — invites opinion
✕
"Think of a time the window was closed." — situational, memory-dependent
✓
"What signals tell you a decision window is closing?" — conceptual, always answerable
✕
"Do you remember a proposal that stalled?" — retrieval question
✓
"What usually causes a proposal to stall?" — concept question
Language

The Writing Rules.
Human, not generated.

EIC materials must read like they were written by a thoughtful human educator, not generated by an AI tool. Two rules are non-negotiable.

Rule 01
No em-dashes in prose
Em-dashes are the clearest marker of AI-generated text. Students notice and it shifts attention from content to production. Replace every em-dash with a comma, semicolon, colon, or a full stop.
Fix it
"The window is open — move now." → "The window is open. Move now."
Rule 02
No situational "you" in module questions
Questions that say "you need to..." or "your CEO..." make the student feel tested. Frame practice questions as scenarios: "The Adriano situation needs to reach the CEO..." not "You need to raise the Adriano situation..."
Fix it
"You need to brief Carlos before..." → "There are 20 minutes with Carlos before..."
Vocabulary

Tooltips.
When and how.

Tooltips make vocabulary accessible without interrupting the flow. Use them for terms that are necessary but potentially confusing for a B1+ learner.

When to tooltip
B2+ terms worth keeping
Some terms are too precise to simplify — "internal sponsor", "structural ally", "escalation", "tenure". Keep them and add a tooltip with the PT translation and an English definition.
Format
PT translation in teal above. English definition in white below. Max 20 words.
When to rewrite
Terms that can be simpler
If a simpler phrase exists that preserves the meaning, rewrite. "Dependencies" → "connected systems". "Domain" → "territory". "Institutional weight" → "credibility and authority".
Test
Would a sharp B1+ student understand this without a tooltip? If yes, rewrite. If no, tooltip.
B1+ terms that always need a tooltip in EIC materials
internal sponsor · structural ally · escalation · tenure · attrition · implementation plan · coalition · receptive · preoccupied · interpersonal · organisational · credible · transition moment · decision window · to frame a proposal · to brief someone

Typography

Type & Layout.

Inter is the only font used across all EIC materials. Loaded from Google Fonts. Never use system fonts or fallbacks as primary.

Font
Inter — all weights
Font family: Inter. Weights used: 400 (body), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold), 900 (black). Italic variants for quotes and prompts.
Import
Inter:ital,wght@0,400;0,500;0,600;0,700;0,800;0,900;1,400;1,700
Layout
Max-width + padding
Content max-width: 1100px centered. Desktop padding: 56-64px. Mobile: 24px. Header: fixed 56px. Tab nav: sticky 48-52px. Views start at 104px margin-top.
Critical rule
Never use animation with transform on parent elements of position:fixed panels — creates stacking context that traps slide-ins.

Process

Deploy in 4 steps.

Run these commands every time you update files. The process takes under 2 minutes.

01
Place files in correct folder
Copy HTML files into the right subfolder inside public/. Student files go in their track folder. Internal files go in internal/.
public/strategic-hr/sdf-lead-in.html
02
Navigate to project folder
Open Terminal and navigate to the Strategichr-filter folder where firebase.json lives.
cd ~/Downloads/Strategichr-filter
03
Run deploy
One command deploys all files in the public folder. Takes about 30 seconds.
firebase deploy --only hosting
04
Verify in browser
Open the URL in an incognito tab to avoid cache issues. Cmd+Shift+N in Chrome.
eic-worksheets.web.app/strategic-hr/
Common issue
404 after deploy
Usually means the files are not inside the public/ folder, or firebase.json has a typo in the public path. Check: cat firebase.json and confirm "public" has no trailing space.
Quick check
ls ~/Downloads/Strategichr-filter/public/strategic-hr/
Good habit
Always deploy from the same folder
The firebase.json file must be in the folder where you run the deploy command. If you run it from a different location, Firebase will not find the config and will error.
Check firebase.json
"public": "public" — no spaces, no slashes
